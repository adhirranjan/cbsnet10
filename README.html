Formats. Markdown (.md) is the hand-authored source of truth everywhere. 10. Doc tooling — how these are generated

Tool Generates
scripts/render-all-docs-html.py Superset renderer. Every .md in the repo → sibling .html (docs/ plus the root docs, per-project READMEs and .claude/ files) and every txt-native doc → sibling .html (verbatim in a <pre>, with a "view raw .txt" link); then rebuilds docs/index.html. Skips a .txt that has a .md sibling — that one is a generated twin and would clobber the Markdown's page. --dry-run, --index-only, --include-plans.
scripts/render-docs-html.py Walks docs/ only and renders every docs/**/*.md → sibling .html. Run via the render-docs-html skill after editing any doc.
scripts/render-deploy-html.py Deployment-doc HTML rendering.
docs/build-docs.mjs legacy-vs-new-components → .txt / .html / .pdf (pure Node + headless Chrome/Edge, zero-install).
docs/architecture/build-arch-doc.mjs TrustBank-CBS-Platform-Architecture → .txt / .html / .pdf / .docx. Takes an optional base-filename + title so a second doc in the same folder reuses the pipeline: node docs/architecture/build-arch-doc.mjs TrustBank-CBS-Architecture-Brief "TrustBank CBS — Architecture Discussion Brief".
docs/architecture-review/build-review-doc.mjs ARCHITECTURE-REVIEW + REMEDIATION-PLAN → .txt / .html / .pdf / .docx.
docs/migration-estimate/build_xlsx.py, build_docx.js, build_pptx.js The estimate workbook, document and deck.
scripts/legacy-screen-inventory.py docs/legacy-inventory/ — the module-wise / module × category screen inventory: README.md, screens.tsv, procs-by-screen.tsv, shared-procs.tsv and the xlsx. Re-run it (then the docs renderer) after a screen is migrated. --dry-run prints the counts only.

At a glance

  • 81 source documents repo-wide — 70 Markdown (docs/, root, per-project READMEs, the mirrored library docs, .claude/) + 11 txt-native. Every one now has an HTML twin. (Counts come from the renderer's own summary line, so re-read them after adding a doc.)
  • 12 dated perf reports; every entry catalogued on index.html, each title opening a rendered page.
  • Biggest reads: the architecture review (~53 KB), the component guide (~37 KB), the CRUD-screen tutorial (~32 KB).
  • Not rendered: .claude/plans/*.md (transient per-session planning scratch). Add them with --include-plans.
