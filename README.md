# TrustBank CBS — Documentation Index

Every document that ships with this solution: what it is, who it's for, and where it lives.

> **Browsable version:** [index.html](index.html) — the same catalogue as a linked HTML page, generated by
> [`scripts/render-all-docs-html.py`](../scripts/render-all-docs-html.py).
>
> **Last updated:** 2026-07-30 · Covers `docs/`, the repo-root docs, and per-project READMEs.
>
> **Formats.** Markdown (`.md`) is the hand-authored **source of truth** everywhere. The `.html`, `.txt`,
> `.pdf`, `.docx`, `.pptx` and `.xlsx` siblings are **generated** — never hand-edit them; regenerate with
> the builder listed in [§10 Doc tooling](#10-doc-tooling--how-these-are-generated). Some older docs are
> `.txt`-native (no `.md` source) — those are marked *txt-native*, and **they are the source of truth for
> their own `.html`** (rendered verbatim in a `<pre>`; edit the `.txt`, then re-run the renderer). A `.txt`
> sitting *next to* a `.md` is a generated twin and shares that document's `.html`.

## 10. Doc tooling — how these are generated

| Tool | Generates |
|---|---|
| [scripts/render-all-docs-html.py](../scripts/render-all-docs-html.py) | **Superset renderer.** Every `.md` in the repo → sibling `.html` (docs/ *plus* the root docs, per-project READMEs and `.claude/` files) **and** every txt-native doc → sibling `.html` (verbatim in a `<pre>`, with a "view raw .txt" link); then rebuilds [docs/index.html](index.html). Skips a `.txt` that has a `.md` sibling — that one is a generated twin and would clobber the Markdown's page. `--dry-run`, `--index-only`, `--include-plans`. |
| [scripts/render-docs-html.py](../scripts/render-docs-html.py) | Walks `docs/` only and renders **every** `docs/**/*.md` → sibling `.html`. Run via the **render-docs-html** skill after editing any doc. |
| [scripts/render-deploy-html.py](../scripts/render-deploy-html.py) | Deployment-doc HTML rendering. |
| [docs/build-docs.mjs](build-docs.mjs) | `legacy-vs-new-components` → `.txt` / `.html` / `.pdf` (pure Node + headless Chrome/Edge, zero-install). |
| [docs/architecture/build-arch-doc.mjs](architecture/build-arch-doc.mjs) | `TrustBank-CBS-Platform-Architecture` → `.txt` / `.html` / `.pdf` / `.docx`. Takes an optional base-filename + title so a second doc in the same folder reuses the pipeline: `node docs/architecture/build-arch-doc.mjs TrustBank-CBS-Architecture-Brief "TrustBank CBS — Architecture Discussion Brief"`. |
| [docs/architecture-review/build-review-doc.mjs](architecture-review/build-review-doc.mjs) | `ARCHITECTURE-REVIEW` + `REMEDIATION-PLAN` → `.txt` / `.html` / `.pdf` / `.docx`. |
| `docs/migration-estimate/build_xlsx.py`, `build_docx.js`, `build_pptx.js` | The estimate workbook, document and deck. |
| [scripts/legacy-screen-inventory.py](../scripts/legacy-screen-inventory.py) | `docs/legacy-inventory/` — the module-wise / module × category screen inventory: `README.md`, `screens.tsv`, `procs-by-screen.tsv`, `shared-procs.tsv` and the xlsx. Re-run it (then the docs renderer) after a screen is migrated. `--dry-run` prints the counts only. |
