Datatype Mapping: CoreDataType / CLR / SQL Server / Oracle

Schema-conversion reference. Defaults mirror the TflOmniDb provider type mappers.

Boolean & integer

CoreDataType CLR / .NET SQL Server Oracle Notes
Boolean bool BIT NUMBER(1,0) Oracle <23c: NUMBER(1) 0/1; 23c+ has BOOLEAN
(none) byte TINYINT NUMBER(3,0) TINYINT is unsigned 0-255; no byte CoreDataType
Int16 short / Int16 SMALLINT NUMBER(5,0)
Int32 int / Int32 INT NUMBER(10,0)
Int64 long / Int64 BIGINT NUMBER(19,0)
(none) long (identity) INT IDENTITY GENERATED AS IDENTITY Identity = KeyGeneration strategy, not a type

Exact numeric

CoreDataType CLR / .NET SQL Server Oracle Notes
Decimal decimal DECIMAL(p,s) NUMBER(p,s) NUMERIC == DECIMAL
Decimal decimal NUMERIC(p,s) NUMBER(p,s) Oracle NUMBER max precision 38
Money decimal MONEY NUMBER(19,4) Avoid PG MONEY (locale); canonical NUMERIC(19,4)
(none) decimal SMALLMONEY NUMBER(10,4) Map to Decimal/Money; range ~ +/-214,748.3647

Approximate numeric

CoreDataType CLR / .NET SQL Server Oracle Notes

Double double / Double FLOAT BINARY_DOUBLE FLOAT(53) = 8-byte double; FLOAT(24)->REAL

Character & text

CoreDataType CLR / .NET SQL Server Oracle Notes
AnsiString string VARCHAR(n) VARCHAR2(n CHAR) Oracle VARCHAR2 <= 4000 bytes (32767 extended)
UnicodeString string NVARCHAR(n) NVARCHAR2(n) Unicode; PG is UTF-8 native (no N-prefix)
AnsiStringFixed string CHAR(n) CHAR(n CHAR) Fixed length, space-padded
UnicodeStringFixed string NCHAR(n) NCHAR(n) Unicode fixed length
Clob string VARCHAR(MAX) CLOB Large ANSI text (> 8000 bytes)
NClob string NVARCHAR(MAX) NCLOB Large Unicode text
Clob string TEXT (legacy) CLOB Deprecated -> use VARCHAR(MAX)
NClob string NTEXT (legacy) NCLOB Deprecated -> use NVARCHAR(MAX)

Date & time

CoreDataType CLR / .NET SQL Server Oracle Notes
Date DateTime / DateOnly DATE DATE Oracle DATE INCLUDES time-of-day (to sec)
Time TimeSpan / TimeOnly TIME(p) INTERVAL DAY TO SECOND Oracle has no TIME-of-day type
DateTime DateTime DATETIME2(p) TIMESTAMP(p) Preferred date+time; p = frac-sec precision
DateTime DateTime DATETIME (legacy) TIMESTAMP(3) ~3.33 ms precision; range 1753-9999
DateTime DateTime SMALLDATETIME TIMESTAMP(0) Minute precision; 1900-2079
DateTimeOffset DateTimeOffset DATETIMEOFFSET TIMESTAMP WITH TIME ZONE Timezone-aware
