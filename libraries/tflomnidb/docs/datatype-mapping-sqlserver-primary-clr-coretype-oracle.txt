General notes
-------------
1. Read left-to-right: this is a SQL-Server-FIRST reference. Find the SQL Server column/parameter type in the left column, then read across for the .NET/CLR type, the TflOmniDb CoreDataType to use, and the Oracle equivalent when porting the schema.
2. Stored procedures: the CoreDataType column is what you pass to StoredProcedureCall.Input/Output(..., CoreDataType.X) and to [DbColumn(CoreType = ...)]. The DAL's per-provider type mappers translate it to the native types shown here.
3. Oracle SP-parameter caveat: a CoreDataType.DateTime parameter binds as DbType.DateTime (TIMESTAMP) on Oracle, NOT DateTime2 - Oracle's managed provider rejects DbType.DateTime2 ('Value does not fall within the expected range'). SQL Server keeps full-precision DateTime2. (CoreTypeDbType.Map.)
4. '(none)' in the CoreDataType column marks a SQL Server type with no canonical enum value - map it to the nearest CoreDataType, or set a per-column native override via [DbColumn] SqlServerType / OracleType.
5. Money is deliberately NUMBER(19,4) to match SQL Server's NUMERIC(19,4) for financial code.
6. Identifier casing: Oracle folds unquoted identifiers to UPPER; SQL Server is case-insensitive. The DAL always quotes - call an unquoted-uppercase Oracle object by its UPPERCASE name.
7. Oracle DATE always carries a time component (to seconds). Use TIMESTAMP for fractional seconds; for pure dates, enforce truncation in the app.
8. Booleans: SQL Server BIT -> Oracle <23c NUMBER(1) 0/1; Oracle 23c+ has a native BOOLEAN.
9. Auto-increment: SQL Server IDENTITY -> Oracle 12c+ GENERATED ... AS IDENTITY; older Oracle needs a SEQUENCE + trigger.
10. Row versioning: there is no Oracle equivalent to SQL Server ROWVERSION. Use an app-managed integer version column (TflOmniDb IsRowVersion) checked in the UPDATE WHERE clause; ORA_ROWSCN is not a drop-in replacement.
11. LOBs: SQL Server (N)VARCHAR(MAX)/VARBINARY(MAX) -> Oracle CLOB/NCLOB/BLOB. Oracle RAW caps at 2000 bytes (use BLOB beyond); VARCHAR2 caps at 4000 bytes (32767 extended).
